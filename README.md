# AI PDF Reader Lite (Tablet & Mobile)

A lightweight, distraction-free PDF reader designed specifically for night-time reading and active studying with a stylus/pen.

## Features
- **Dual Input Architecture**: 
  - **Finger**: Fluid scrolling, panning, and zooming (never draws accidental lines).
  - **Stylus / Pen**: Real text-snapping highlighting (no freehand scribbles).
- **Zero-Friction Ergonomics**: Never switch back-and-forth to a "neutral / hand" tool.
- **5 Luminous Night Colors**: Amber 🟡, Emerald 🟢, Cyan 🔵, Violet 🟣, and Rose 🔴.
- **Eye-Care Night Themes**: OLED Pure Black, Charcoal Violet, Warm Sepia, and Day Paper.
- **Highlights Drawer**: Categorized by page with 1-click **Export to Obsidian** markdown.
- **Offline First**: Runs 100% offline via local IndexedDB and Service Worker caching.
